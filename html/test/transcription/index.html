Janus AudioBridge - Transcription Test

Transcription Test Application

Test App: This application connects to a Janus AudioBridge room with 2 dummy peers that play audio files. Use the mute/unmute buttons to control when audio is sent to Janus for transcription.

Instructions

  1. Place two audio files (peer1.wav and peer2.wav) in the same directory as this HTML file
  2. Click "Start" to connect to Janus
  3. Click "Load ABMod" to enable transcription
  4. Use the mute/unmute buttons below to control dummy peer audio
  5. Watch the transcription appear in real-time
